# GitHub Repository Naming Convention

## Rules
- Lowercase only — `my-project`, not `My-Project`
- Use hyphens, not underscores or spaces — `my-app`, not `my_app` / `My App`
- No special characters (`a-z`, `0-9`, `-` only)
- No trailing hyphens or dots
- Keep it short and descriptive

## Patterns

| Pattern | Example | Use case |
|---|---|---|
| `noun-noun` | `image-resizer` | Tools, libraries |
| `verb-noun` | `parse-yaml` | Utilities |
| `org-prefix` | `stripe-node` | SDKs, bindings |
| `x-cli` | `git-cli` | CLI tools |
| `awesome-x` | `awesome-react` | Curated lists |
| `dotfiles` | `dotfiles` | Personal configs |

## Tips
- Match repo name to package/module name
- Avoid filler prefixes like `my-` or `new-`
- Check name availability on GitHub/npm/PyPI before publishing
